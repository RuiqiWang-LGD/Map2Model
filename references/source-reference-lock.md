# 明显地物定位与相对宽度硬性检查

适用：源图中河流、海岸、洲岛、跑道、大型广场外缘或主要道路等边界清楚，且位置、宽度会决定建模底图正确性的项目。它们是图像内的定位参照，不自动构成地理坐标系或真实米制尺度。本页强化原图定位要求；不改变片区与详图的对象保留范围，不把片区删减规则迁入详图。

## 先建立原图参照

在生图或构造前，从原始影像独立记录分散的岸线转折、洲岛端部、桥梁两端和路口；明显弯曲水系须覆盖上游、中段、下游和各主弯段，不能只检查中央一段。明确边界角色（水陆实际界、车行道边、道路总占地等），排除阴影、树冠、屋顶和水面亮带。

沿各对象自身法向记录成对边界端点、长度及原图像素单位，另选未参与构造的控制点/断面复核。直段可用横向断面；斜弯段不能拿水平投影宽度冒充法向宽度。记录图像尺寸、文件哈希和显示变换，源图与候选必须处于同一画幅。

## 无尺寸也必须保持比例

没有可靠实际尺寸时，保留相对单位，不能以“没有尺寸”为由任意加粗道路。每条检查道路选择附近、同一可信成像范围内的明显参照断面，计算 `r_source = w_road_source / w_reference_source`，候选须保持同一比值。河宽是局部参照，随河段变化；不能给全图所有道路套统一“河宽十分之一”，也不能单独缩放河流或道路。至少同时检查参照物本身的两侧位置、宽度及道路的两侧位置、法向宽度，避免两者一起放大却让比值看似正确。

“河道30米、图上3厘米、道路0.3厘米”只说明比例推理；除非用户明确该对象、位置、测量含义和真实数值，否则不能把示例30米记作项目定标。单幅倾斜或拼接影像可能只有局部可信比例，须说明限制，不从一个参照宣称全图测绘准确。

## 通过条件与修复

构造前按源图边界可辨误差、最窄保留道路和建模用途制定本项目的位置/宽度/比值容差，写明单位及来源；不预设跨项目通用像素、百分比或米数，也不能为让当前失败通过而事后放宽。单个断面通过不能代替全段或全图；遮挡和分类不确定的段落分别标记。

输出二维图前与最终 CAD 回读后，分别检查：独立控制点残差、上下游双岸位置、各断面参照宽度、道路宽度及道路/参照宽度比。保存原图与当前简图或实际CAD几何的同框叠图；用户需要时提供可调透明度对照。对照页只进行已记录的完整画幅缩放，不自动平移、旋转或局部拉伸来掩盖错位。

默认可调透明度叠图仅叠加“原始卫星/正射影像＋最新修改稿”，滑块只调整最新稿的透明度；不混入旧稿，不提供旧版切换。每次改图同步更新叠图到最新版本及其文件哈希；历史版本仅归档，用户明确要求历史对比时才另外制作。

明显地物位置或相对宽度超出依据充分的容差，属于未通过；不能把好看的生成稿标为定位合格，也不能直接据此描 CAD。回到原图局部重建真实边界、路宽、桥头及邻接块面，不全图弹性扭曲。生成工具无法保住坐标时，可改用原图坐标下的可编辑矢量构造并重新检查；无法完成的段落明确列为未通过，不声称“以后CAD会修”就已经合格。

源图对齐、表达取舍、CAD拓扑、SU编辑和用户认可分别记录。只修正河道及沿河道路时如实标明修正范围，不能用该局部通过替整个路网背书。关联错例：[EF010-C](error-library/cases/EF010.md#ef010-c)。
