# 案例复核入口

统一维护位置为 [错例索引](error-library/index.md)，检索/去重/同步方式见 [维护流程](error-library/maintenance.md)。本页保留项目记录合同，不再维护第二套错例表。

每轮在 process/case-review.md 记录：问题族与变体、源图及 CAD 版本哈希、用户现象、源侧依据、旧检查漏掉的范围、修复动作、前后验证、相邻影响、未解决项和归类理由。图片按需局部同尺度对比；没有修改后成果不造成功图。过程记录在任务未完成时保留，最终验收后按 [文件保留与清理](output-lifecycle.md) 同步已获授权且有复用价值的增量，再清理无依赖临时材料；未合并情况在当前任务说明，默认不另建永久修改记录或过程存档。

被同一方法再次解决的同类问题记录独立发生次数；出现新的结构、旧修法失败或不同用途就增加变体。原始完整资料留项目内，已审核的泛化案例同步到已授权维护的库。新场地重新判断源侧条件，不复用旧坐标/阈值。没有后台任务、跨用户上传或自动权重学习。
