# SU 前期底图：可见平面与独立选面合同

版本前提：按 [设计范围合同](design-scope.md) 建立用户选定版本的期望对象。清空版的范围内非道路对象列为已授权清除，不要求恢复或加入父块子环；以独立的范围与保留道路证据检查留白及接边，不能用候选结果自证清空正确。原图叠图中的这类差异不作为漏绘。

适用于默认的 SU 前期规划、分区上色和推拉底图。先决定哪些对象应当可选，再构造线网；成品由一套可见的共面分区组成。闭合、零重线和文件可打开只是必要条件，不能证明用户可以选到预期的道路、水面或地块。

## 默认成果的组成

| 对象 | 应得到的实际面 |
|---|---|
| 连续的同层道路及其路口 | 每个有依据的连续道路区域是一个可独立选择、上色的面；交接处没有横向封口、拼缝或细节线 |
| 主路与桥面 | 保持连续完整占地；下层道路、河岸、平台及其他低优先线在其可见占地外止住，实际裁掉占地内部分 |
| 水域 | 每个可见连续水面独立成面；真实桥面遮挡造成的可见分量分别成面并关联到同一水体对象 |
| 主要父块 | 完整外边界围出独立背景面，允许建筑/内部块形成有语义的孔洞；不由大量碎面拼凑一个应当完整的父块 |
| 建筑与有作用的内部块 | 各自独立成面并有明确归属；不侵入主路、不破坏父块外缘，合理院落与真实窄通道保留 |

桥下道路的现实通行关系可以保存在语义记录中；平面表达中的遮挡裁断不代表现实道路被拆除。不同层级不能误成平交路口，也不能把完整桥面环叠在未裁的地面线网上。所有实体 Z=0 时，图层、组名和类别不产生几何高差；原始可见线网检查必须同时包含它们。

先按 [分级围合](hierarchy-and-regular-geometry.md) 判明一级路、围合父块与二三级路的用途及选面目标。属于同一建模路面的同层相接道路才合并连续路面并去内部边，再与父块共享唯一边界。不同用途的路缘/平台交界按依据分面，不因“道路优先”将内外通路全部合面；也不为保环制造阻断真实通道的假封口。真实分隔带、交通隔离、图框裁切和桥梁遮挡可能形成多个合理可见面，数量与同面关系从源图确定；不要求全图道路或跨桥水域强行只有一个面。

独立选面、独立编辑和封闭实体是不同目标。平面闭合与同异面检查不能认证实际推拉互不影响；用户反馈联动时按 [目标与排查分支](hierarchy-and-regular-geometry.md) 检查实际模型。图层不同不保证隔离，但无组结构也不足以确诊联动根因。默认平面合同不因此自动改为逐块编组或三维实体交付。

## 大边界与形体简化

大地块与水域之间默认只保留一条有空间意义的分界。没有独立规划用途的窄岸带、岸顶岸脚成对线、重复平行轮廓与碎小过渡块，归入相邻大面并记录取舍。确有独立步行、通行、平台或设计作用的窄带按明确对象保留，不能仅因窄就删除。共享边只构造一次，两侧对象通过边链引用它。

优先规整一级、二级道路的大范围边界和建筑轮廓：直边按对象自身主方向拟合，真实圆弧保持曲率；用源图精度、对象尺度和最窄必留通道设置局部偏移、短边候选及曲线弦高预算。低于一像素的简化可能保留整排台阶，不是规则化完成的证明。输出尺度下仍有明显栅格锯齿、回折、无意义短折线串或被铺装串联的建筑时返修；短边长度/顶点数只触发复核，不禁止有依据的小转角、必要短边或真实窄面。不能仅增大几何容差放行，也不把真实 L/U 形、斜翼、院落和自然曲岸统一矩形化。

不确定中小块面按路网、邻接及场地用途判断：优先保证一级、二级道路连续、干净且有实际宽度，再以有依据的主边界合理闭合背景，决定保留独立小块、归并相邻同用途区域、按图框收边或记录待查。归并不得跨路、吞入口/通道或改变有依据的用途；闭合分面辅助边须明确区别现状实体线。机械补缝和逐个保住所有像素碎面都不能代替此判断。按 [案例复核与复用](case-review.md) 记录所选方案及被检验的结果。

## 构造之前：独立的源侧期望

建立 `process/source-contract.json` 及必要的源图说明，先于待检线网生成并保存哈希。它独立于构造 manifest，也不混入 `check_cad.py` 的项目 JSON。字段按 `check_visible_plan.py --help` 与随附示例填写，以下证据没有机器字段时保存在关联说明中：

- 源图文件/哈希、像素尺寸、坐标变换、用户用途、尺度状态和简化预算。
- 必要对象的 `id, role, source_region, parent, visibility_priority, expected_visible_components`；跨层对象同时记录现实关系与本图遮挡关系。
- 源图独立选取的内部探针、道路法向断面与桥头/水陆局部；哪些探针必须属于同一实际面，哪些必须分属不同面。连续主路取分散探针，不能只取一点。
- 主路/桥面应完整的范围、不得出现其他边线的内部区域；主要父块外缘/截边和水陆唯一边界的检查区。范围来自图像判断或用户约束，不能由待检 CAD 反算。
- 每个保留窄带及真实分割的空间作用；必须保留的转角、曲率、通道与允许的形体近似。

构造配方、候选 mask 或 `object-manifest` 可以提供索引和候选形体，不能单独充当验收真值。导出后再补实际 handle/边链/面 ID 对应表，保持源侧记录与导出清单分开。源侧错误可以依据新图像证据修订并重跑；不得为了迁就当前 CAD 的碎面数改写期望。源侧探针与选区必须覆盖用户主要使用对象，少量探针通过不证明未覆盖区域。

## 导出之后：同时满足的门

从实际最终 DXF 重读全部可见实体；DWG 转换后对回读 DXF 执行同一检查，记录文件哈希、脚本、命令、参数与逐对象结果。

| 门 | 必须留下的证据与失败条件 |
|---|---|
| 原生几何 | 闭合/孔洞、Z、唯一物理边、实际端点交会、图框及无自交/残线。修复必须写回实体再重读；不能先 snap、union 或节点化修好再称原始文件通过 |
| 主路内部零干扰 | 对源侧主路/桥面占地的内部逐段检查所有实际可见边。非该面的外缘/有依据孔洞边进入内部即失败；道路图层自身的横向封口同样失败，不按图层名称豁免 |
| 实际选面对应 | 原始线网分出的面与源侧对象/同面组逐项对应；同面探针落到同一实际面，异面探针落到不同面；再核对完整外缘、孔洞和面积范围。仅数量相等、单点命中、或先合并碎面再比面积均不足 |
| 边界唯一性 | 共享物理边只出现一次；另在指定水陆/大块邻界的横断检查区识别近邻平行线和夹出的窄条，逐条关联其独立作用。没有作用的第二条边或狭长碎面失败；精确重线检测不能替代此门 |
| 形体规则化 | 优先检查一二级道路大范围边界与建筑轮廓；按源侧预算统计短边串、连续交替小转角、直边法向偏移、曲线弦高和局部碎面，结合源图核对明显锯齿区及代表性局部。栅格台阶、无意义折线或建筑地面拖尾失败；合理小转角/短边保留，减少总顶点数不等于通过 |
| 完整图回归 | 外层已接受对象及同面关系仍成立；加入建筑/细节后无新主路分割、父块碎面或重边；格式回读一致，叠图来自同一文件 |

运行可见平面检查器：

复制 [源侧合同示例](../examples/visible-source-contract.json)，用当前源图替换占位路径、哈希、全部观察点和预算。合同坐标以左上为原点，单位与待检 CAD 一致；原生 DXF 映射为 `x=x, y=height-y`。已缩放或配准的项目须先用固定变换转换独立源侧观察，不能把像素值直接混入米制 CAD。检查器支持平面 LINE 和无 bulge 的 LWPOLYLINE；源图文件或哈希变化会拒绝继续。锯齿 `roles` 是边界图层名中的匹配片段，须覆盖本图实际道路、建筑边界层，不能留空来跳过重点对象。

```text
python "<Skill绝对目录>/scripts/check_visible_plan.py" drawing.dxf --contract source-contract.json --report report.json
python "<Skill绝对目录>/scripts/check_visible_plan.py" final-roundtrip.dxf --contract source-contract.json --report roundtrip-visible-plan.json --manifest visible-surfaces.json
```

`--contract` 必须是独立源侧合同；可选 `--manifest` 只补充完整面形状/导出对应，不能取代源侧证据。检查器覆盖原始全部可见线的节点、重叠、残线与分面，`same_face_groups`/`distinct_groups`、保护主路走廊内部干扰、`single_boundaries` 横断数量、`width_probes`、道路/建筑交替短折齿、最短有效边与最小碎面。阈值按源图精度及必要通道/真实短边确定，不能照搬案例值。语义取舍、源侧合同是否有据及异常是否属于真实形状，仍需源图复核和案例记录。机器所判范围、采样/实体支持及未执行项以实际报告为准。

`check_cad.py` 的跨层重叠只是 warning；`check_face_hierarchy.py` 只适用其声明的独立多边形环范围；`cad_pipeline.py` 的 complete 只表示配置步骤完成。它们不能单独证明本合同。共享边/曲线等超出当前检查器范围时，按 [等效证据合同](cad-modules.md#工具范围外的等效证据合同) 在项目实现并运行缺失门，报告不得标成已由随附 CLI 自动检查。未执行项为 pending/not_run；失败或未检查时成果仍为候选。

原始 CAD 的选面对应是 SU 使用条件的可检验前提，不能冒充真实 SU 导入、选面、上色或推拉已执行。只有对当前最终文件实际测试并留证时才声称 SU 通过；不因未操作 SU 而免除上述 CAD 门，也不为普通 CAD 任务新增强制 UI 操作。

## 用户明确要求详细高差时

用户明确要求保留岸顶岸脚、桥下道路、分层建模或指定细部时，按该请求记录需保留对象、表示方法与独立验证范围；不套默认省略。完整下层几何可放过程参考或单独的详细成果，保留可追溯关系。详细多层模型采用明确独立平面/对象的组织并验证实际选择隔离；没有可靠标高就不编造 Z。若还交付默认 SU 平面版，其可见线网仍执行本合同；不能把详细参考线混入该平面后靠关闭图层使其通过。

## 用户封面反馈与碎图门

用户反馈局部漏面或碎裂时，原区域 pass 作废。读取 [局部封面检查](region-face-check.md)，新增覆盖真实失败点的独立源侧条件，先在旧版重现漏检，再在修正版复检。有限全局同面探针不覆盖所有街坊；优先保路，其次保块，容许有界简化。不得将数值上仅有细缝相连认作可用道路。


## 原图定位先于拓扑验收

现状任务有原始影像时，道路和父块位置的 source-contract 必须有原图独立观察。选定分析图的轮廓可作候选，但不能独自决定验收目标。将实际线网回投原图，按 [原图边界关卡](shared-rules.md#原图边界关卡) 先核对边界角色、位置、宽度及出入口，再执行本合同的拓扑门。原图检查失败时，拓扑 pass 和分析图 IoU 不能提升交付状态。

## 低清晰度重构对象的道路退让

所有场景的难辨内部细节按 [通用重构合同](low-clarity-reconstruction.md) 设定项目间距 g，并在构造及 CAD/DWG 回读中核验；任务包含 SKP 交付或实际模型检查时，再核验实际 SKP，未运行的项目如实记录。g 应覆盖源图表达不确定度与输出链路数值风险；正间距不能代替道路面的内孔和重叠检查。保留真实道路接入口与可靠的现状共边，重构背景不自动产生一圈保护带实体。现有 CLI 未覆盖的部分按等效证据合同补验，不虚称脚本自动通过。
